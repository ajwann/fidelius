# Fidelius

Landing page for Fidelius, a theoretical cryptography startup. Static HTML, served by GitHub Pages.

## Structure

- `index.html` — the full page (inline CSS/JS, Google Fonts)
- `assets/logo-mark.svg` — standalone line-art logo mark (brand color `#170626`)
- `assets/favicon.svg` — favicon
- `.nojekyll` — serve files as-is, skipping Jekyll

## Publishing

In the repo, open **Settings → Pages**, set **Source** to *Deploy from a branch*, and pick `master` / `/ (root)`.
The site is served at `https://fideli.us` (see `CNAME`).
